# 大符右灯臂调光台

在工程根目录运行：

```powershell
python -m http.server 8771 --bind 127.0.0.1 --directory frontend
```

用桌面版 Chrome 或 Edge 打开 [右灯臂调光台](http://127.0.0.1:8771/)，点「连接串口」，选择 `LED54 Right Arm`（USB VID/PID `239A:80DA`，此设备当前为 COM22）。「离线演示」可在没有硬件时操作界面。

## 固件和输出

- 右灯臂使用 54 颗 WS2812，nRF52840 的 `P0.09` 接首颗 DIN，供电为板载 3.3 V 与 GND。
- 调光固件为根目录的 `led54_control.uf2`。重新构建运行 `python build.py`，进入同一设备的 UF2 bootloader 后刷入。上一版固定蓝光固件为 `led54_blue.uf2`。
- 开机发出熄灯帧，随后以 `B=4` 常亮。网页滑块范围为 `B=0..8`。等效占空比为 `B / 255`，串行数据位时序固定。
- 网页发送非零亮度后，固件开启通信保护。串口断开或 2 秒内收不到心跳时熄灯。点「断开串口」会先发送熄灯指令。

## 实时回报

页面约每 500 ms 读取 USB 串口回报，同时显示目标和固件确认的等效占空比。回报包含驱动状态、RGB、引脚、灯珠数、数据位时序、刷新间隔、帧数、停灯原因和运行时间。VDD 和芯片温度来自 nRF52840 内部采样，灯板端的电压、电流和温度需要另接传感器。

串口为 115200，使用 DTR，每条命令以换行结束，回复一行 JSON。设备标识为 `board: "right-arm"`，协议为 `LED54/1`。

| 命令 | 用途 |
| --- | --- |
| `GET` | 读取最新状态 |
| `SET 0` 至 `SET 8` | 设置蓝光档位，越界返回 `LIMIT` |
| `KEEP` | 维持网页已设置的非零输出 |
| `?` | 单行简短诊断，可省略换行 |
